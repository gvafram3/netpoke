# netpoke

MPhil Computer Science thesis project (KNUST) extending **SlowPoke**
(Xie et al., NSDI 2026) so its throughput predictions stay accurate for
I/O-bound microservices, not only compute-bound ones.

- **[`netpoke/`](netpoke/README.md)** — the thesis project: overview, current
  status, how to replicate the experiments, thesis chapters, design docs.
  Start here.
- **[`slowpoke/`](slowpoke/README.md)** — the SlowPoke artifact itself
  (application code, the `poker` pause controller, evaluation scripts), with
  NetPoke's changes on top.
- [`slowpoke_nsdi_2026.pdf`](slowpoke_nsdi_2026.pdf) — the base paper.
