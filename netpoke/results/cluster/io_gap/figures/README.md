# I/O-gap figures (cluster)

Generated on **netpoke-control** after logs are present:

```bash
cd ~/slowpoke/evaluation
python3 io_gap/plot_io_gap_rmse.py results/ -o results/fig_io_gap_rmse.png
```

Copy into this directory when syncing:

```bash
cp ~/slowpoke/evaluation/results/fig_io_gap_rmse.png \
  netpoke/results/cluster/io_gap/figures/
```
