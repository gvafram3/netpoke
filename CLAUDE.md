# Project instructions

## Writing style

Before finalizing any written prose output (explanations, docs, commit messages, reports, chapter/section text in `netpoke/docs/`, etc.), run it through the `anthropic-skills:humanizer` skill's principles to strip AI-writing tells (inflated symbolism, promotional language, superficial "-ing" analyses, vague attributions, em dash overuse, rule-of-three, AI-vocabulary words, passive voice, negative parallelisms, filler phrases). This applies for the rest of every session in this repo, not just when explicitly requested.
